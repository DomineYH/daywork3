# 우리 반 역할 나누기

index.html을 브라우저에서 열어 실행합니다. 설치·로그인·API 키가 필요 없습니다.

학생 이름을 한 줄에 하나씩 입력하고 역할 나누기를 누르세요. 환경 정리, 학습 도우미, 준비물 관리, 질서 도우미에 고르게 배정합니다. 공백·중복 입력은 거절하며 마지막 줄바꿈 하나는 허용합니다. 이름이나 결과를 저장·전송하지 않습니다. 호스팅 제공자의 접속 기록은 별개입니다.

## 검증
실제 index.html JavaScript를 Node.js에서 7명·8명 각각 10,000번 실행: 누락·중복 0, 역할별 인원 차이 최대 1명. 잘못된 입력 10가지 거절. 브라우저 DOM/화면 검증은 별도입니다.
